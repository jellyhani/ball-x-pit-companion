# BALL x PIT Companion — ไทย

[🌐 Languages](../../README.md#choose-your-language)

โปรแกรมช่วยเล่น BALL x PIT บน Windows ที่ไม่เป็นทางการ อ่านสถานะเกมเพื่อแนะนำการเลือกเมื่อเลเวลอัป การผสาน การปลดล็อกสารานุกรม การเก็บเกี่ยว และการจัดฐาน ผู้เล่นยังเป็นผู้ควบคุมเกมเอง

## การติดตั้ง

ต้องใช้ Windows 10/11 และเกม BALL x PIT เวอร์ชัน Steam ที่คุณติดตั้งเอง หากมี ZIP ในหน้า [Releases](https://github.com/jellyhani/ball-x-pit-companion/releases) ให้แตกไฟล์ทั้งหมดแล้วเปิด `BallxPitCompanion.exe` โดยเก็บโฟลเดอร์ `_internal` ไว้ข้างกัน หากยังไม่มีรุ่นเผยแพร่ ให้ติดตั้งจากซอร์สตามด้านล่าง โปรแกรมไม่มีลายเซ็นดิจิทัล จึงอาจมีคำเตือนจาก SmartScreen

ดาวน์โหลดคลังโค้ด เปิด PowerShell ในโฟลเดอร์นั้น ติดตั้ง uv แล้วเริ่มการตั้งค่า:

```powershell
winget install --id=astral-sh.uv -e
powershell -ExecutionPolicy Bypass -File setup.ps1
```

จากนั้นเปิด `run_overlay.bat` การตั้งค่าจะดาวน์โหลดส่วนประกอบที่จำเป็นและ BepInEx แล้วดึงข้อความกับไอคอนจากเกมของคุณ โปรดออกจากเกมตามปกติเพื่อติดตั้งหรืออัปเดตตัวเชื่อมต่อ ตัวติดตั้งจะรอขณะที่เกมยังทำงาน

## วิธีใช้

- ตรวจสอบการเชื่อมต่อในหน้าตั้งค่า แล้วเปิดหน้าจอเลเวลอัปหรือผสานเพื่อดูคำแนะนำ
- เปิดโหมดสารานุกรมในการตั้งค่าการแสดงผลเพื่อให้ความสำคัญกับการค้นพบ โดยค่าเริ่มต้นจะปิดอยู่
- เปรียบเทียบผังปัจจุบันกับผังแนะนำ แล้วเลื่อนสิ่งปลูกสร้างด้วยตนเองตามลำดับ
- เส้นทางและผลเก็บเกี่ยวเป็นค่าประมาณ การเข้าถึงได้จากหลายมุมไม่ได้หมายความว่าจะเก็บครบในการยิงครั้งเดียว

## ความเป็นส่วนตัวและข้อจำกัด

ตัวเชื่อมต่ออ่านข้อมูลเท่านั้น ไม่ใช้แพตช์ Harmony ไม่แก้ไขเซฟ และไม่ส่งคำสั่งควบคุมเกม บันทึกและข้อมูลที่ดึงมาจะอยู่ใน `%LOCALAPPDATA%\BallxPitCompanion` โดยไม่อัปโหลดประวัติการเล่น รุ่นระยะแรกนี้ทดสอบหลักบน Windows 11 ความละเอียด 1920×1080 ภาษาเกาหลี และเกม 1.301 ไม่รับประกันผังที่ดีที่สุดหรือ DPS ในอนาคตที่แม่นยำ คำแปลยังไม่ได้รับการตรวจจากเจ้าของภาษาครบทุกภาษา และไม่ใช่ผลิตภัณฑ์ทางการ

## การแก้ปัญหาและรายงาน

หากไม่เห็นโอเวอร์เลย์ ให้ตรวจการแสดงผล หน้าต่างเกม และการเชื่อมต่อ เมื่อรายงานใน [Issues](https://github.com/jellyhani/ball-x-pit-companion/issues) ให้ระบุรุ่น ภาษา ความละเอียด ขั้นตอน ผลที่คาดหวัง และผลจริง ลบข้อมูลส่วนตัวออกจากภาพและบันทึกก่อนแชร์ และอย่าอัปโหลดเซฟหรือทรัพยากรที่ดึงมาจากเกม

## สิทธิ ความรับผิดชอบ และความเป็นส่วนตัว

เครื่องมือนี้ไม่ใช่ผลิตภัณฑ์อย่างเป็นทางการและให้บริการตามสภาพ สิทธิในเกมและเนื้อหาของบุคคลที่สามเป็นของเจ้าของสิทธิแต่ละราย สิทธิที่กฎหมายห้ามยกเว้นยังคงมีผล
