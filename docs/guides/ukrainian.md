# BALL x PIT Companion — Українська

[🌐 Languages](../../README.md#choose-your-language)

Неофіційний помічник для BALL x PIT у Windows. Читає стан гри та радить вибір під час підвищення рівня, злиття, відкриття енциклопедії, збору ресурсів і розміщення бази. Грою керуєте ви.

## Встановлення

Потрібні Windows 10/11 і ваша власна інсталяція BALL x PIT зі Steam. Якщо в [Releases](https://github.com/jellyhani/ball-x-pit-companion/releases) є ZIP, розпакуйте його повністю та запустіть `BallxPitCompanion.exe`, залишивши поруч теку `_internal`. Якщо випуску немає, скористайтеся вихідним кодом за інструкцією нижче. Програма не підписана й може викликати попередження SmartScreen.

Завантажте репозиторій, відкрийте PowerShell у його теці, встановіть uv і виконайте налаштування:

```powershell
winget install --id=astral-sh.uv -e
powershell -ExecutionPolicy Bypass -File setup.ps1
```

Потім запустіть `run_overlay.bat`. Налаштування завантажить залежності й BepInEx та видобуде тексти й піктограми з вашої гри. Для встановлення або оновлення з’єднання завершіть гру звичайним способом; поки вона працює, встановлювач чекає.

## Використання

- Перевірте з’єднання в налаштуваннях і відкрийте екран підвищення рівня або злиття.
- Увімкніть режим енциклопедії в налаштуваннях відображення, щоб надавати перевагу відкриттям; спочатку він вимкнений.
- Порівняйте поточне й запропоноване розміщення та вручну перемістіть будівлі в зазначеному порядку.
- Траєкторії та обсяги збору є прогнозами. Доступ із кількох кутів не означає збирання всього одним пострілом.

## Приватність і обмеження

З’єднання лише читає дані: без патчів Harmony, змін збережень або керування грою. Журнали й видобуті дані залишаються в `%LOCALAPPDATA%\BallxPitCompanion`; записи гри не надсилаються на сервер. Ранню версію перевіряли переважно у Windows 11, 1920×1080, корейською, у грі 1.301. Оптимальне розміщення й точний майбутній DPS не гарантовані. Не всі переклади перевірили носії мови. Це не офіційний продукт.
